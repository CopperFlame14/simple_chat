❓ Help & Support

🎯 Getting Started Guide

Follow this step-by-step guide to set up and run the Two-Way SCP project.

Step 1: System Requirements

Ensure your system meets the following requirements:

  • Operating System: Linux, macOS, or Windows with MinGW
  • Compiler: GCC with C99 support and pthread library
  • Memory: Minimum 4MB available RAM
  • Network: Localhost connectivity for testing

Step 2: Compilation & Building

Compile the project using the provided Makefile:

# Clone or download the project
$ cd two_way_scp_project/src

# Compile both client and server
$ make

# For manual compilation:
$ gcc -std=c99 -pthread -o scp_server_two_way scp_server_two_way.c
$ gcc -std=c99 -pthread -o scp_client_two_way scp_client_two_way.c

Step 3: Running the System

Start the server and client in separate terminals:

# Terminal 1 - Start Server
$ ./scp_server_two_way
🟢 Server listening on port 8080...

# Terminal 2 - Start Client
$ ./scp_client_two_way
Enter your name: Alice
✓ Connected to server

Step 4: Using the Two-Way Protocol

Experience bidirectional communication:

  • Client to Server: Type messages in client terminal
  • Server to Client: Server sends automatic responses and status updates
  • Simultaneous Messaging: Both sides can send messages at the same time
  • Reliability: Automatic retry on packet loss or timeout

🔧 Troubleshooting Common Issues

❌ Compilation Errors

Problem: "pthread.h not found" or similar errors

Solution: Install pthread development packages:

# Ubuntu/Debian
$ sudo apt-get install libpthread-stubs0-dev

# CentOS/RHEL
$ sudo yum install glibc-devel

# macOS (usually included)
# No action needed

# Windows (MinGW)
$ pacman -S mingw-w64-x86_64-pthreads

❌ Connection Refused

Problem: "Connection failed" when starting client

Solution: Ensure server is running first and check port availability:

# Check if server is running
$ ps aux | grep scp_server

# Check port 8080 availability
$ netstat -tulpn | grep 8080

# If port is busy, change PORT in source code

❌ Permission Denied

Problem: "Permission denied" when binding to port

Solution: Use a higher port number or run with appropriate permissions:

# Change to a higher port (10000+)
#define PORT 10000

# Or on Linux, allow non-root to use lower ports:
$ sudo setcap 'cap_net_bind_service=+ep' ./scp_server_two_way
